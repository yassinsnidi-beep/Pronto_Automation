Prontobox Scouting · guida operativa

Portare il pannello su un altro PC

Dieci passaggi, in ordine, per far funzionare lo scouting settimanale — scraper, skill e pannello — su un computer che parte da zero. Una volta finiti questi, per l'uso di tutti i giorni resta valida la guida README.md già nella cartella.

Da fare su: il PC nuovo, non su questo Tempo previsto: 30–40 min di installazioni + un margine imprevedibile la prima volta che Idealista/Immobiliare incontrano l'anti-bot Sistema: Windows
1

Google Chrome

obbligatorio

Gli scraper di Idealista e Immobiliare non usano il Chromium interno di Playwright: aprono il Chrome vero installato sul sistema (channel="chrome"), perché ha un'impronta digitale meno riconoscibile dall'anti-bot dei due siti (DataDome).

Se sul PC nuovo non c'è già, installalo da google.com/chrome prima di ogni altro passaggio.

2

Python 3.9 o successivo

obbligatorio

Da python.org/downloads. Durante l'installazione, spunta "Add python.exe to PATH" — senza questa spunta, il file .bat del pannello non troverà Python e si fermerà subito con un errore chiaro a riguardo.

3

Node.js (versione LTS)

obbligatorio

Serve solo per installare la CLI di Claude Code al passo successivo. Da nodejs.org, scegli la versione LTS. Verifica dopo l'installazione, da un terminale nuovo:

// in un terminale (PowerShell o cmd), su un PC nuovo
node --version
npm --version
4

CLI di Claude Code + accesso

obbligatorio

È il motore che scrive la valutazione testuale di ogni opportunità ogni settimana — il pannello lo lancia da sé, senza intervento manuale, ma deve trovarlo installato e già collegato a un account. Serve un account Claude proprio di chi userà il PC (non si eredita da un altro computer): la valutazione consuma l'uso/i crediti di quell'account.

npm install -g --allow-scripts=@anthropic-ai/claude-code @anthropic-ai/claude-code

Poi, dallo stesso terminale, avvia una prima volta l'accesso interattivo e segui le istruzioni a schermo per collegare l'account:

claude
Nota

Se npm install segnala uno script di post-installazione bloccato ("allow-scripts"), è quello mostrato sopra con --allow-scripts — senza, la CLI si installa ma un passaggio interno non gira.

5

VS Code + estensione Claude Code

consigliato

Questo è il modo per parlare con Claude interattivamente sul nuovo PC — esattamente come stiamo facendo io e te ora — utile per farsi aiutare a correggere uno scraper, capire un errore nel log, o modificare la configurazione. È un uso diverso e separato dalla CLI del passo 4 (quella lavora da sola dentro il pannello).

  1. Installa Visual Studio Code
  2. Dal pannello estensioni (Ctrl+Shift+X), cerca "Claude Code" e installala
  3. Apri la cartella Pronto_Automation come cartella di lavoro (File → Apri cartella)
  4. Avvia l'estensione e accedi con lo stesso account del passo 4
6

Copia i file del progetto

obbligatorio

Il modo più semplice: copia l'intera cartella Pronto_Automation sul PC nuovo (chiavetta, disco di rete, o uno ZIP via WeTransfer). Due cartelle vanno escluse sempre:

Porta con te

  • Avvia Prontobox Scouting.bat
  • README.md
  • pannello/
  • .claude/skills/prontobox-scouting/ (intera, incluso reference/*.csv)
  • scrapers_v2/*.py + requirements.txt
  • opportunities/ (struttura cartelle; i dati dentro sono facoltativi)
  • requirements.txt nella radice

Lascia indietro

  • scrapers_v2/profilo_chrome_idealista/
  • scrapers_v2/profilo_chrome_immobiliare/
  • __pycache__/ (ovunque)
  • *.log (rumore, non servono)
Perché escludere i profili Chrome

Sono cookie di sessione legati all'impronta di questo PC: copiarli su un altro computer non aiuta — DataDome lega il cookie al dispositivo che l'ha ottenuto — e insieme pesano quasi 800 MB di roba inutile a chi li riceve.

Se vuoi includere anche i dati già raccolti (i dataset delle aste, Idealista, Immobiliare): sono file grandi — solo dataset_immobiliare_completo.json supera 1 GB. Escludendo i profili Chrome di cui sopra, il totale resta comunque entro i 2 GB del piano gratuito di WeTransfer.

7

Dipendenze Python del progetto

obbligatorio

Da un terminale, dentro la cartella Pronto_Automation appena copiata:

// libreria per leggere config.yaml (o la installa da solo il .bat al primo avvio)
pip install -r requirements.txt

// Playwright + parsing HTML, usati dagli scraper
pip install -r scrapers_v2\requirements.txt

// indispensabile: dice a Playwright di usare il Chrome vero installato al passo 1
playwright install chrome
8

Verifica che la skill sia al posto giusto

una tantum

Se hai copiato l'intera cartella al passo 6, questo passaggio è già a posto: controlla solo che esista

Pronto_Automation\.claude\skills\prontobox-scouting\scout.py

Se invece stai ripartendo da un semplice file prontobox-scouting-skill.zip (senza il resto del progetto), estrailo dentro .claude\skills\prontobox-scouting\ — a mano, oppure chiedendolo a una sessione di Claude Code aperta su quel PC.

9

Primo avvio del pannello

obbligatorio

Doppio clic su Avvia Prontobox Scouting.bat. Si apre una finestra nera (lasciala aperta) e dopo un paio di secondi il browser mostra il pannello su http://127.0.0.1:8765/. Nella schermata Home, premi Avvia scansione settimanale.

10

Cosa aspettarsi da Idealista e Immobiliare

da sapere

Su questo PC, la prima scansione ha incontrato un blocco anti-bot che ha richiesto una pausa di alcune ore prima di sbloccarsi. È probabile che capiti di nuovo su un profilo Chrome nuovo di zecca: non è un errore da correggere, è normale rodaggio.

  • Tieni d'occhio la finestra Chrome che si apre durante questa fase: se compare un controllo anti-bot, risolvilo a mano appena possibile (hai circa 20 secondi prima che lo script riprovi da solo)
  • Se si blocca per 3 città di fila, lo script si ferma da solo invece di insistere all'infinito — è voluto
  • Se resta bloccato, chiudi tutto e riprova dopo qualche ora: è quasi sempre un limite temporaneo legato alla sessione, non un guasto
Sei pronto quando…
  • python --version, node --version e claude --version rispondono tutti da un terminale nuovo
  • Pronto_Automation\.claude\skills\prontobox-scouting\scout.py esiste
  • Il doppio clic su Avvia Prontobox Scouting.bat apre il pannello nel browser senza errori di Python mancante
  • La Home del pannello mostra il pulsante Avvia scansione settimanale
Per l'uso settimanale una volta installato — schermate Home / Avanzamento / Risultati / Storico, come cambiare config.yaml, problemi comuni — resta valida README.md nella cartella del progetto.
